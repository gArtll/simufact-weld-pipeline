# How it works

## Inputs

| Input | Format | Field |
|---|---|---|
| base meshes (web / tube, plate) | BDF, GRID* + CHEXA, mm | `base.web_bdf`, `base.plate_bdf` |
| weld window | Simufact weld line CSV `order;activity;x;y;z` | `sides[].window_csv` |
| heat source | Simufact heat source XML (`wlWeldingParameter`) | `heat_source.xml`, `heat_source.entity_name` |
| process parameters | Simufact process XML | `process.parameters_xml` |
| materials | Simufact `.xmt` (`sfMaterialData`) | `materials.base_xmt`, `materials.filler_xmt` |
| constraints | fixed node CSV / tooling surface ARC | `fixed_nodes_csv`, `constraints` |
| reference case (optional) | `.dat`, `robots_properties.xml`, result ARC, bead section JSON | `reference.*` |
| machine settings | `config.yaml` (from `config.example.yaml`) | `hmbatch`, `runscript`, `arctool`, `work_root` |

Field list: [`case_schema.md`](../case_schema.md).

## Cases in the repository

| case.json | Geometry | Base mesh | Reference case | Runs without Simufact |
|---|---|---|---|---|
| `cases/example_synthetic.json` | fillet web on plate | written by `cases/example_synthetic/make_example.py` | none | `prep`, `gate --self` |
| `cases/example_tube_synthetic.json` | tube on plate, closed ring | written by `cases/example_tube_synthetic/make_example.py` (4,800 + 1,152 CHEXA) | none | `prep`, `gate --self` |

Both cases are synthetic: every mesh, window and XML is generated by the script next to it from made-up values
(`cases/synthetic_xml.py` writes the process and heat-source XML; they are not Simufact exports). The weld line of
the ring is a polygon through mesh nodes, so `window_expected_length_mm` is the perimeter of the inscribed polygon,
`2*n*R*sin(pi/n)` for the n ring nodes, and the R19 check compares against the mesh's own value.

## Pipeline

| Step | Directory | Tools | Simufact | Output |
|---|---|---|---|---|
| preflight | — | `common/preflight.py`, `common/rules.yaml` | no | block / warn / ok list |
| hm (optional) | `00_hm` | `hm/params.py`, `hm/tcl_gen.py`, `hm/pipeline.py`, `hm/meshio.py` (hmbatch) | no | `base_web.bdf`, `base_plate.bdf` |
| prep | `01_prep` | `prep/wl_v2.py`, `prep/mesh_bead.tcl` (hmbatch) or `prep/mesh_bead.py`, `prep/bead_outer_line.py`, `gate/check_bead_nodes.py`, `gate/check_detj.py` | no | root line, bead BDF, outer-surface weld line, bead checks |
| build | `02_build` | `build/build_project.py` (runscript), `build/patch_trajectory.py`, `build/contact_table_gen.py` | yes | new Simufact project |
| gate | `03_gate` | `build/write_input.py` (runscript on a copy), `gate/check_short_v3.py` | yes | `.dat` input check vs reference case |
| gate `--self` | `03_gate` | `common/selfdat.py`, `gate/check_short_v3.py` | no | `.dat` assembled from `01_prep`, input check against itself |
| run | `04_run` | `build/write_input.py`, `gate/check_short_v3.py --allow AUTO_STEP`, `run/start_analysis.py` | yes | solver run, `.sts` exit number |
| compare | `05_compare` | `run/compare_temperature.py`, ArcToolCmd | ArcTool | same-section peak temperature difference |
| post (optional) | `07_post` | `run/post.py`, `run/probes.py`, `run/arccsv.py`, `run/solver_stats.py`, ArcToolCmd | ArcTool | probe thermal cycles, t8/5, final values, solver statistics |
| regress / test | `06_selfcheck` | `gate/run_regressions.py`, `tests/` | no | regression table, unit tests |

Per step: `manifest.json` — input SHA-256, outputs, duration, exit code, checks. Non-empty step directory → refusal.

## 母材网格步骤

`python weldsim.py hm <case.json>`. A project case is meshed from its STEP by the plan's backends: explicit web (`hm/explicit_web.py`, `mesh_transition/web.py`) and the plate swept (`plate.py`) or mapped (`mapped_plate.py`), in whatever orientation the part comes; the block is completed from `plan/plan.json` ([fields](../case_schema.md#filled-from-the-plan-project-cases-00_hm)). The parametric HyperMesh automesh below is kept for the regression cases only (`case.json` block `base_mesh`, fixed frame, does not read CAD); `hmbatch` empty → "未配置 HyperMesh，跳过 hm 步骤", exit 0.

| Stage | Content |
|---|---|
| frame | plate top y = 0, width X centred on 0, length Z from 0, thickness −Y; web normal X, centred on x = 0, height +Y |
| geometry | plate top rectangle and web side rectangle from line loops (`*linecreatestraight`, `*surfacesplineonlinesloop`) |
| zones | plate: planes x = ±(t_web/2), ±(t_web/2 + band), ±(t_web/2 + 2·band); web: planes y = h1, h2 (multiples of the zone size); split by planes only (TCL4) |
| sizes | weld band `weld_band_size_mm`; transition × `transition_ratio` (≤ far size); far `far_size_mm`; web first row ≥ 5 mm (prep root-line edge rule) |
| meshing | zones finest first (TCL1), quads (`*automesh` type 1), marks 1 / 2 only (TCL2), no model file I/O (TCL3) |
| solids | `*meshdragelements`: plate −Y by thickness, `plate_layers`; web +X by thickness, `web_layers`; 2D elements deleted |
| export | Tcl dump of node coordinates and element connectivity (full double precision) → Python: rounding 1e-9 mm, renumbering in HyperMesh id order, positive winding, optional curvature map, GRID* + CHEXA / CPENTA BDF |
| quality | penta fraction (CPENTA count / element count) ≤ `max_penta_fraction`; min corner scaled Jacobian ≥ `min_scaled_jacobian` (this project's definition: per corner, determinant of the three unit edge vectors; minimum over all elements — not the HyperMesh Jacobian metric); no tetrahedra; plate layers ≥ `plate_layers`; web bottom-face and plate top-face nodes on the analytic plate surface (gap < 1e-6 mm) |
| retries | penta fraction over limit → weld band size − `shrink_step_mm`; scaled Jacobian under limit → `transition_ratio` − 0.5 (≥ 1.0) and weld band width × 2 once; at most `max_retries`; every attempt with its mesh values in `attempt_<k>/` and `manifest.json` |
| downstream | `00_hm` exit 0 → prep, build, `gate --self` use `00_hm/base_web.bdf`, `00_hm/base_plate.bdf` |

Web and plate: separate node sets (contact, no shared nodes), same as the existing cases.

## prep

| Stage | Method | Check |
|---|---|---|
| root line | web face quads at face X (planar) or ring face at axis value (closed circular); boundary edges with both nodes within 5 mm of a plate node; longest chain; resampling | R8 \|x − face\| < 1e-6 mm; CSV newline |
| bead sections | equal arc length along the root line, `spans = floor(L / spacing)`; tangent by central difference (h = 0.5 mm); web leg `n_web × t` oriented into the web face; plate leg `t × w` oriented to the weld side; `tube_on_plate` frame: axial leg + radial leg | — |
| bead template | 7 nodes / 3 quads per section (Simufact quality level 0), 3 CHEXA per span; winding by signed volume | R2 detJ at 2×2×2 Gauss points, non-positive = 0 |
| node snapping | contact-face nodes (local 0, 1, 2, 5, 6) closer than `bead.micro_snap_mm` (0.01 mm) to a base node → exact coincidence | near-coincidence band 1e-6–1e-2 mm count = 0 |
| outer-surface line | local node 5 (hypotenuse midpoint) polyline; window end points projected, not snapped (R19); `bead.points` resampling | R19 length difference < 0.01 mm |
| bead distance | nearest base node distance per bead node; bands < 1e-6 / 1e-6–0.1 / > 0.1 mm; histogram | R3 / R20 |

`prep/mesh_bead.py`: same arithmetic order and BDF text as `prep/mesh_bead.tcl`; selected by an empty `hmbatch`.

## build

| Stage | Content |
|---|---|
| project | `new_project`, `new_process`, temperature, materials, components, bead geometries |
| weld lines | outer-surface lines from `01_prep` (R13, R14), `local-vector` (R18) |
| trajectories | `new_trajectory`, `new_geometry`, heat source, `calculate_all_orientations(search_radius=5 mm)` once (R6′, R17) |
| constraints | fixed nodes (1 node per group) or bearing + clampings |
| process | `import_all_settings`, end time, parallelisation, save |
| trajectory patch | `calculation`, `orientation_mode`, `connect_to_nodes`, variation angle / offset from `sides[].trajectory` (R4, R7) |

## Input check (`gate/check_short_v3.py`)

| Item | Criterion |
|---|---|
| ORIENT | torch orientation tables: same table and row count; arc length ≤ 1e-5 m; direction component ≤ 2e-3 → within tolerance (R23) |
| CONTACT_TABLE | block count and content identical (comments ignored) |
| AUTO_STEP | block count and content identical |
| NDSQ | heat source path node sets: same count; position difference < 0.001 mm; `--independent-bead` < 0.005 mm |
| BEAD_SET | bead element set count and sizes |
| PROC | `connect_to_nodes`, `calculation`, `orientation_mode`, variation angle / offset, `reference_volume` radius (1e-9 m) |
| BEAD_DIST | near-coincidence band ≤ reference; `--independent-bead`: 10 µm band ≤ reference and full band ≤ reference × 1.1 (R20) |
| DETJ | non-positive Gauss points = 0 |

Five key sections: NDSQ, ORIENT, CONTACT_TABLE, AUTO_STEP, BEAD_SET.
Exit: 0 pass / pass with allowed difference / within tolerance; 1 fail; 2 usage.
Allowed difference: `--allow ITEM` (short runs: `AUTO_STEP`, block-count-only `CONTACT_TABLE`).

## run / compare

| Stage | Content |
|---|---|
| copy | `02_build` project copy without `_Run_`, `_log`, `_particles`, `_Results_`, `_watch_tmp`, `project.lock` |
| `.dat` | `write_program_input` at run end time; input check `--allow AUTO_STEP` |

## post

`python weldsim.py post <case.json>` — optional, needs a finished `run` step and a `post` block in `case.json`
([fields](../case_schema.md)). Not a comparison with a reference case: it extracts what one model produced.

| Stage | Content |
|---|---|
| probes | physical coordinates (mm) from `post.probes`, resolved on the first exported increment (the undeformed mesh) to the nearest node of the named body; the distance is reported |
| too far | further than `max_distance_mm` is a verdict about the mesh, not about the probe: *this mesh cannot reliably represent this point*. The step fails and names the points. The nearest node's own cycle is still written, marked `[REFERENCE ONLY]` with `comparable_across_meshes: false`, and must not be compared with another mesh's value at that point |
| why coordinates | two meshes of the same part number their nodes differently, so a node number compares nothing across meshes; the probe distance says how well each mesh can represent the same physical point |
| history | `TEMPTURE` of every selected increment at the probe nodes; increment → time from the `.sts` table; node index is followed through the increments (later coordinates are the deformed ones) |
| metrics | peak and its time; t8/5 by linear interpolation of the cooling branch between 1073.15 K and 773.15 K; cooling rate at 973.15 K; `samples_in_window` and `max_gap_in_window_s` say how coarse the interpolation was; no value is produced when the cycle does not cross both temperatures |
| sampling check | `PKTEMP` (the solver's own per-node maximum) minus the sampled peak = `peak_missed_by_sampling_K`: what the output interval hides |
| final values | `post.final_values` at the probes in the last exported increment (default `PKTEMP`, `TOTDISP`, `EFFPLS`, `EFFSTS`; solver units m / Pa / K) |
| solver statistics | `run/solver_stats.py`: exit number, load cases, increments, retried increments, progress, wall / CPU time, post and restart file writes, inverted elements from every domain `.out` |
| output | `post.json`, `probe_history.csv`, `post_summary.txt`, `manifest.json` with one check per probe |

Exported CSVs are deleted unless `post.keep_csv` is set: a full export of every increment runs to gigabytes.

## Regression cases (`gate/run_regressions.py`)

17 cases: input check on stored `.dat` / `Proc` copies with expected exit, FAIL, allowed difference and within-tolerance sets. `.dat` copies not in the repository → missing inputs reported as skipped. Private copies: env `WELDSIM_REGRESSION_CASES`.

## Parameter library (`library/`)

`参数库_v1.csv`: one row per case × mesh; value + provenance per cell; `weldsim suggest` ranking by joint type, process, material class, thickness, confidence, solver exit.

## Status page (`ui/`)

`streamlit run ui/app.py`: read-only view of `runs/<case>/0x_*/manifest.json`, logs, preflight, suggest.

## 添加新接头类型要改什么

**必须先有一个在 Simufact 界面里搭好、求解算通（exit 3004）的参照算例。没有它，gate 没有比较对象，温差没有基准；AI 替代不了。**

| # | 改动 | 位置 |
|---|---|---|
| 1 | 焊道截面模板与截面坐标规则 | `prep/mesh_bead.py`、`prep/mesh_bead.tcl` |
| 2 | 焊缝边识别 | `prep/wl_v2.py`、`prep/wl_geom.py` |
| 3 | 接触模板 | `build/rulesets/<name>.yaml` |
| 4 | 参照算例（界面搭建、exit 3004）与抽取脚本 | `cases/<name>/reference/`、`cases/<name>/extract_reference.py` |
| 5 | 参数库记录（没有则 `suggest` 无命中，参数由用户或文献入库流程提供） | `library/参数库_v1.csv` |
| 6 | 回归用例 + 单元测试；原有回归全部仍一致 | `gate/run_regressions.py`、`tests/` |

Tube-on-plate (E4) followed these six items.
